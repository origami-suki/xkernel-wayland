## 学习实验

运行 `git -C sources/x-kernel rev-parse v0.2.0` 和 `git -C sources/x-kernel rev-parse 'v0.2.0^{commit}'`。两个值不同：前者标识 annotated tag 对象，后者标识真正的代码提交。查看 `git submodule status`，集成仓库锁定的是后者。
