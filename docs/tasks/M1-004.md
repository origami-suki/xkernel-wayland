# M1-004：Wayland 的 Unix STREAM fd 传递与共享映射

- 目标：在最小 wl_shm 客户端前证明共享文件能跨进程传递、映射并正确释放；对应 COMPAT-01、WAYLAND-01。
- 依赖：M0-002 的可运行环境；M1-001 提供相同程序/ABI 的 Linux 对照。可与 Weston 补包、DRM 原语验证并行。
- 修复前静态证据：`net/knet/src/unix/stream.rs` 和 `stream/channel.rs` 未携带 ancillary；`posix/net/src/cmsg.rs` 已解析 SCM_RIGHTS，DGRAM 有状态传递，但不代表 STREAM 可用。已有 memfd/seals/shared mmap 应先测后修。
- 范围：先最小复现，再实现所需 STREAM 语义与生命周期回归；不重写所有 Unix socket 或 mmap。

## 可独立验收的步骤

1. Linux/x-kernel 运行同一两进程探针：创建 `socketpair(AF_UNIX, SOCK_STREAM)`，通过 `sendmsg` 发送标记字节和共享文件 fd，接收端 `recvmsg` 后 `mmap`；检查标记、有效接收 fd、同一对象的双向可见内容。两个进程的 fd 数字可以相同，不能据此判断是否传递成功。
2. 在现有实现复现“字节收到、fd 缺失”等实际现象，记录返回值、errno、控制数据长度、进程与文件生命周期；不能只按源码给动态用例判失败。
3. 修复已复现的语义后验证短读/分段、多 fd、控制缓冲不足、发送端关闭原 fd、接收侧提前退出、CLOEXEC 和资源回收，并对现有 STREAM 唤醒和 DGRAM 做必要回归。错误与截断行为按 Linux 对照，不统一返回成功。
4. 对共享文件验证 truncate、MAP_SHARED、seals 和父子可见性。接口探针通过后交给 M2-001 做实际 `wl_shm` pool/buffer 的提交与 release 验证；该集成结果不反过来阻塞本卡的低层接口验收。

修改内核前按其 AGENTS 和相关技能补读实现/测试约定；实际修复按独立问题拆成任务/提交，记录构建、静态检查、针对性用例及回归，不在此卡预填成功命令。

- 实际执行：2026-09-25 已运行 Linux/x-kernel 同盘探针并修复 STREAM 传递；独立验收进行中，memfd seal 执行缺口另行收尾。
- 实现状态：进行中；STREAM 与 memfd seal 分别验证和提交。
- 证据状态：原始 before/after 和 Linux 对照已保存；尚未完成全卡验收。
- 用户学习/任务验收：待完成。

## 学习实验

接收 fd 后关闭发送者原 fd，再从接收端读取/修改映射。说明 fd 数字、进程 fd 表、共享文件对象、VMA 分别由谁拥有，以及 Wayland 为何需要传递文件对象而不是发送一个整数。

## 2026-09-25 实测与修复记录

入口为 `tests/unix-rights/rights.c`、`scripts/prepare_rights_tests.py`。缺少上游 skill 示例中的本地 Starry harness，沿用本项目已有的相同赛方 rootfs、静态 musl C 探针与两个 guest runner，不下载替代 rootfs。ABI 对照依据 Linux unix(7)/recvmsg(2)，并以盘内 Linux 6.12.110 实际结果验证。

初版 11 项：host 与 `m1-rights-linux-before-20260925` 均通过；`m1-rights-xkernel-before-20260925` 中 8 项失败，guest/runner exit 1 被保留。STREAM 收到字节但 fd 数量为 0，4+1+4 的控制数据屏障被合并成 9 字节；DGRAM 的基础 fd 传递已通过。memfd 的 SHRINK seal 可以读取，却未阻止 ftruncate。

增强版另外验证 socket 对端 EOF（最后引用回收）、接收进程退出、连续 rights 消息、部分读取后合并普通尾部、同一 open file description 的共享位置，并先检查 fcntl 返回非负。fixture v1/v2/v3 各有独立镜像和 manifest，不覆盖原证据。

STREAM 修复保留原 byte ring，在每个方向附加与字节位置关联的 control FIFO。短读只交付一次引用；recv 不跨越尚未消费的控制数据尾界；发送者关闭原 fd、无控制缓冲、截断、接收者关闭/退出均按所有权释放。posix 层处理 CMSG 对齐、CLOEXEC、截断后能装入的 fd、EMFILE 和控制数据拷贝失败的回滚。具体锁顺序与界限见两个 crate 的 design/security 文档。

明确限制：原有 Unix MSG_PEEK 尚未实现非消费语义；循环传递 Unix socket 形成引用环的 GC 尚未实现。这些不属于本卡 Wayland 非循环共享文件传递的通过声明。完整 Weston/wl_shm 集成仍交 M2-001，不以接口探针代替显示证据。
