## Leader / worker

- Leader 负责范围、分支、任务卡、证据核对和整合。
- Capture worker 独占 QEMU 权限，冻结输入、串行采集两侧、校验导出，保存日志与 monitor 图像；全机最多一个 QEMU，运行期间不并发构建。
- Analysis worker 不运行 QEMU，独立检查 Perfetto 查询口径，分析新 trace，编写比较报告；与 capture worker 的文件归属分离。
- 结果依赖 worker 时，leader 使用 Agent 等待工具阻塞等待，不重复采集或分析。

## 验收与证据

1. 两侧真实新跑且输入可比，保留失败记录、实际命令、主机状态、准确产物和输入哈希。
2. 分别核对 monitor 原页显示、trace 导出完整性、guest/QEMU/runner 退出；三者不互相替代。
3. Perfetto SQL 与原始输出可复查，按应用里程碑比较；明确 CPU 覆盖、嵌套、采样误差、追踪开销和缺失事件。
4. 给出实测热点排序及能区分假设的下一项最小验证；不把缺少调度/内核事件的等待归因到具体内核函数。
5. 运行项目检查、核对文档与证据链接，归档并验证新增关键证据后提交；不推送。
